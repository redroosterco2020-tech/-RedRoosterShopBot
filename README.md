# 🤖 ربات فروش تلگرامی سیلو

ربات دستیار فروش تلگرام برای فروش محصولات دام و طیور (تخم‌مرغ، جوجه، نیمچه، پولت، مرغ و خروس) با
فروشگاه، ثبت و پیگیری سفارش، اطلاع‌رسانی موجودی، پشتیبانی و بخش اطلاعات.

## امکانات

- 🛍 **فروشگاه** — مشاهده‌ی همه محصولات، دسته‌بندی، جستجو، موجودی لحظه‌ای
- 🥚 **محصولات** — دسترسی سریع به همه‌ی محصولات + نشان «محصولات جدید»
- 💰 **قیمت روز** — نمایش قیمت لحظه‌ای همه‌ی محصولات با یک لمس
- 📦 **ثبت سفارش** — فرآیند گام‌به‌گام: انتخاب محصول → تعداد → شهر → آدرس → تماس → تأیید نهایی
  و صدور خودکار کد سفارش (مثل `SB-A2K9X`)
- 🚚 **پیگیری سفارش** — با وارد کردن کد سفارش، وضعیت (در انتظار / آماده ارسال / ارسال شده / تحویل شده) نمایش داده می‌شود
- 🔔 **اطلاع‌رسانی موجودی** — کاربر برای محصول ناموجود ثبت‌نام می‌کند و به‌محض موجود شدن پیام دریافت می‌کند
- 💬 **پشتیبانی** — پیام کاربر مستقیم برای مدیر فوروارد می‌شود؛ مدیر با Reply روی همان پیام پاسخ می‌دهد
- 📍 **اطلاعات** — درباره ما، قوانین، ساعات کاری، موقعیت روی نقشه، شبکه‌های اجتماعی
- 🛠 **پنل مدیریت** (با دستورات متنی) — تغییر موجودی، مشاهده و تغییر وضعیت سفارش‌ها، پیام همگانی

## پیش‌نیازها

- [Node.js](https://nodejs.org) نسخه ۱۸ یا بالاتر
- یک توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)

## نصب و راه‌اندازی

### ۱. گرفتن توکن ربات

۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید.
۲. دستور `/newbot` را بزنید و نام و یوزرنیم دلخواه را وارد کنید.
۳. توکنی که برایتان می‌فرستد را کپی کنید (چیزی شبیه `123456789:AAExample...`).

### ۲. گرفتن آیدی عددی مدیر (ادمین)

به ربات [@userinfobot](https://t.me/userinfobot) پیام دهید تا آیدی عددی خودتان را بگیرید.
اگر چند نفر می‌خواهند مدیر باشند، آیدی همه را با کاما جدا کنید.

### ۳. نصب وابستگی‌ها

```bash
npm install
```

### ۴. تنظیم متغیرهای محیطی

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید، سپس مقادیر را جایگزین کنید:

```bash
cp .env.example .env
```

```env
BOT_TOKEN=توکن-ربات-شما
ADMIN_IDS=آیدی-عددی-شما
```

### ۵. اجرای ربات

```bash
npm start
```

اگر پیام `🤖 ربات فروش سیلو با موفقیت اجرا شد.` را دیدید، یعنی ربات آماده است. حالا در تلگرام
به ربات خودتان پیام `/start` بدهید.

## ویرایش محصولات و اطلاعات فروشگاه

- **محصولات**: فایل `src/data/products.json` را ویرایش کنید (نام، قیمت، موجودی، واحد، توضیحات).
  برای تغییر سریع موجودی وقتی ربات در حال اجراست، از دستور ادمین `/setstock` استفاده کنید تا
  اطلاع‌رسانی خودکار «دوباره موجود شد» هم فعال شود.
- **درباره ما / قوانین / ساعات کاری / نقشه / شبکه‌های اجتماعی**: فایل `src/data/settings.json`
  را ویرایش کنید. بعد از ذخیره، ربات را ری‌استارت کنید.

## دستورات مدیریتی (فقط برای آیدی‌های داخل `ADMIN_IDS`)

| دستور | کاربرد |
|---|---|
| `/admin` | نمایش راهنمای دستورات مدیریتی |
| `/products` | لیست محصولات به‌همراه شناسه (id) و موجودی |
| `/setstock <شناسه> <تعداد>` | تغییر موجودی یک محصول — مثال: `/setstock rooster 12` |
| `/orders` | لیست سفارش‌های در انتظار / آماده ارسال |
| `/setstatus <کد سفارش> <status>` | تغییر وضعیت سفارش؛ status یکی از: `pending`, `ready`, `shipped`, `delivered`, `cancelled` |
| `/broadcast <متن>` | ارسال پیام به همه‌ی مشتریانی که تاکنون سفارش ثبت کرده‌اند |

برای هر سفارش جدید، پیامی همراه با دکمه‌های سریع «آماده ارسال / ارسال شده / تحویل شده / لغو» هم
مستقیماً برای مدیر ارسال می‌شود؛ لازم نیست حتماً دستور تایپ کنید.

### پاسخ به پیام‌های پشتیبانی

وقتی کاربری از منوی «💬 ارتباط با پشتیبانی» پیام بفرستد، همان پیام برای شما (مدیر) فوروارد
می‌شود. کافیست روی همان پیامِ فوروارد‌شده در تلگرام **Reply** بزنید و پاسخ را تایپ کنید — ربات
به‌صورت خودکار آن را برای همان کاربر ارسال می‌کند.

## نکات فنی

- داده‌ها (محصولات، سفارش‌ها، مشترکین اطلاع‌رسانی، پیام‌های پشتیبانی) در فایل‌های JSON داخل
  `src/data/` ذخیره می‌شوند — نیازی به دیتابیس جداگانه نیست. برای حجم فروش بالا یا استفاده‌ی
  چند-سروری، پیشنهاد می‌شود این بخش به یک دیتابیس واقعی (مثل PostgreSQL یا SQLite) مهاجرت داده شود؛
  تمام توابع مربوط به داده در `src/db.js` جمع شده‌اند و جایگزینی آن‌ها ساده است.
- وضعیت گفت‌وگوی هر کاربر (مثلاً مرحله‌ی فعلی ثبت سفارش) در حافظه نگهداری می‌شود، یعنی با
  ری‌استارت ربات، سفارش‌های نیمه‌کاره (که هنوز تأیید نشده‌اند) از بین می‌روند — سفارش‌های
  تکمیل‌شده در `orders.json` باقی می‌مانند.
- برای اجرای همیشه‌روشن (production)، ربات را روی یک VPS با ابزاری مثل [pm2](https://pm2.keymetrics.io/)
  اجرا کنید یا از سرویس‌هایی مثل Railway / Render استفاده کنید:
  ```bash
  npm install -g pm2
  pm2 start src/bot.js --name silo-bot
  ```
